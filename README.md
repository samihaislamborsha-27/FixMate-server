# FixMate – Backend API

This repository contains the backend API for FixMate, a smart home appliance repair and service booking platform.

## Live API
https://fixmate-server-izjk.onrender.com

## Features
- Authentication and user management
- Role-based access control
- Service management
- Booking management
- Customer and technician operations
- Administrator operations
- Stripe payment integration
- MongoDB database integration

## Technologies
- Node.js
- Express.js
- MongoDB
- Better Auth
- JWT
- Stripe

## Installation
```bash
npm install
```

## Run Locally
```bash
npm run dev
```

The backend uses environment variables for configuration. Create a `.env` file locally with the required settings. Never upload secret keys or passwords to GitHub.
